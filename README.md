# ResumeForge — Free Resume Builder

Create professional resumes for free. No sign-up required.

- **4 ATS-friendly templates** (Minimal, Professional, Modern, Classic) with live previews
- **Live A4 preview** while you type
- Custom accent colors, fonts, photo toggle
- **PDF export** via print, **autosave** drafts in your browser
- **20 languages**, light / dark / system theme
- 100% client-side — your data never leaves your browser

Built with Astro 5 + React + Tailwind CSS.

Live: https://dusmamud.github.io/resumeforge/
